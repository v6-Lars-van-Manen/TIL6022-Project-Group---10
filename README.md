# TIL6022 Project Group 10: Rail sabotage and road traffic on the A1

This project investigates whether the railway disruptions on the
Amersfoort–Apeldoorn–Deventer corridor on 15 September 2026 led to
measurable changes in traffic intensity and average speed on the
parallel A1 motorway. Traffic on the disruption day is compared with
a baseline of regular Tuesdays, using NDW Dexter open data.
The severity of the railway disruptions is quantified using open data from Rijdendetreinen.nl

## Contents

- `project_proposal.ipynb`: Project notebook (proposal stage)
- `project_proposal.html`: HTML export of the notebook (proposal stage)
- `final_project_group_10.ipynb`: Project notebook (final)
- `final_project_group_10.html`: HTML export of the notebook (proposal stage)
- `3_Visualization_traffic_intensity_and_speed.ipynb`: Analysis and visualization Traffic Speed and Intensity
- `Analysis_traindisruption.ipynb`: Analysis and visualization Severity Railway Disruptions

## How to run

All required datasets are included in the repository and can be found in the data and data_dexter folders. The analysis was developed in Python using pandas, NumPy, Matplotlib and Seaborn. To reproduce the results, open and run the provided Jupyter notebooks. 

## Data

NDW Dexter open data: https://dexter.ndw.nu/opendata/overview
Rijden de treinen open data: https://www.rijdendetreinen.nl/open-data/treinarchief#downloads (For the months August, September and October 2026)
